# Substitution-cipher

Input file:- io_file.txt<br>

This Python program reads characters one by one from an input file (`ip_file.txt`) and writes them into an output file <br>(`op_file.txt`) using a dictionary that maps each ASCII letter to itself. <br>
The dictionary is created using `string.ascii_letters`, and for every character read, if it exists in the dictionary, <br>
its mapped value is written; otherwise, the character itself is written. <br>
The program continues until the end of the file is reached, <br>
printing each processed character along the way.<br>
