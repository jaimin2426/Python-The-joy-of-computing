2. Next, run the Python file → Execute the script generate_map.py from your terminal or command prompt.<br>
3. The Python file will read the CSV → It will take all the coordinates (locations) from your coords.csv.<br>
4. The Python file will create an HTML file → It automatically generates a file named map.html which contains the map.<br>
5. The HTML file will open automatically → After running the script, your browser will open map.html.<br>
6. Click the “Go Live” button → On the web page, you will see a “Go Live” button. Click it.<br>
7. Your coordinates will appear on the map → All the points you entered in the CSV will be shown as markers on the map.<br>
